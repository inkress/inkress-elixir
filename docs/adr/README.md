# Architecture Decision Records

This folder records **decisions that were non-obvious, debated, or easy to
re-litigate** — so we don't re-argue them from scratch later.

Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)
(Status / Context / Decision / Consequences). One file per decision, numbered
sequentially, immutable once Accepted — supersede with a new ADR rather than
editing an old one.
